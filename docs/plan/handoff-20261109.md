### 1.2 组件管理契约 v1

配置文件：`<state>/supervisor/supervisor.toml`，其中 `<state>` 在本机是 `~/.local/share/acb/state`（不是 `~/.local/state/acb`，后者只放日志）。
结构：`[supervisor]` + 顶层数组 `[[component]]`；所有清单结构 `deny_unknown_fields`，写错字段直接拒绝启动。

| 字段 | 取值 | 默认/说明 | 证据 |
|---|---|---|---|
| `type` | `simple` / `oneshot` | 默认 `simple`；`notify` 是预留值，v1 未实现 | `crates/supervisor/src/component.rs:42-63` |
| `readiness.kind` | `process` / `tcp` / `http` / `exit` | `exit` 仅 oneshot 用 | `component.rs:110-129` |
| `readiness` 阈值 | `interval_secs=5`、`failures_threshold=5`、`success_threshold=3`、`startup_grace_secs=60` | 契约 §5.3 | `component.rs:17-26` |
| `restart.policy` | `always` / `on-failure` / `never` | 默认 `on-failure`，有界退避 | `component.rs:132-155`, `275-298` |
| `depends` | `after` / `requires` / `part_of` / `wants` | `after` 对 oneshot 是事件语义 | `component.rs:300-310` |
| `process.kill_mode` | `process` / `group` | 默认 `group` | `component.rs:157-178` |
| `stop_action`（oneshot） | `down` / `leave_running` | 默认 `leave_running` | `component.rs:180-201` |
| 停止超时 | 45s | 契约 §5.2/§5.4 | `component.rs:25-26` |

关键运行时语义：

- **oneshot 事件式重跑**：依赖组件每次进入 `healthy` 会把“就绪代次”加一；oneshot 记录上次执行时各 `after` 依赖的代次快照，依赖重新就绪就重跑一次。证据：`crates/supervisor/src/component_runtime.rs:85-88, 356-398, 952-...`。
- **组件失败不升级成桥的失败**：失败只写组件状态（`<state>/components/*.json` 的 `failed` / `last_result`），不会设置 supervisor 的退出码，不会触发 78，也不会改写 profile 指针 `current.json`。证据：`component_runtime.rs:543-547`；`crates/supervisor/src/lib.rs:785-795`（`exit_code` 只由 supervisor 自身状态产生）。
- 组件状态查询以 `acbctl component status` 为准；不要直接猜 JSON 字段。

### 5.3 哪些操作必须用户在场

| 操作 | 原因 |
|---|---|
| `nixos-rebuild switch` | 需要 sudo，会替换系统层 acbl |
| `acbctl upgrade --payload ...` | 会停旧 bridge、提交指针、请求 systemd 重拉；服务中断 |
| 修改 `~/.local/share/acb/config/config.toml` | 现场配置是唯一真源；改完要重启桥 |
| `acbctl up/down`、`systemctl --user restart acb-bridge` | 会动现场服务 |
| `acbctl unit install-user` / 删除 nix-config 最后一个 unit | 改变 systemd 所有权，需先确认 |
| `git push`、`--amend`、任何历史改写 | 用户明确禁止未经授权的推送和历史改写 |

### 5.4 会浪费一小时的坑

| 坑 | 规避 |
|---|---|
| 以为 `nixos-rebuild switch` 就换了 bridge | 它只换 acbl/系统入口；payload 换代必须 `acbctl upgrade --payload`（`profile seed` 是 no-op） |
| 把现场 `acbctl --help` 当 HEAD 的子命令面 | 现场是 `36e3e41`；`sessions scan/migrate-preset` 只在 HEAD |
| 拿 `send_message` 的异步任务测 `wake_on_completion` | 发送尝试记录固定 `wake_on=never`，不会走完成唤醒；先确认 `create_task_record` 的工具入口 |
| 只改 `config.active.toml` | 本机启用 notifications，active 是启动前从 `config.toml` 生成的派生文件；改源文件再重启 |
| 把 `fix/tool-delivery-reachability` 整支合入 | 该分支 tip `a699e95` 未并入，但内容已 cherry-pick；先核对是否重复 |
| 用 `acbctl down` 后只看 unit 状态 | `KillMode=process`，launcher 收到 SIGTERM 后会收敛 bridge/组件；必须看端口和组件状态 |
| 直接调 `dsh` 调参 | 包装器每次启动会覆盖 profile manifest；调试用 `dsh-real`（文档记录如此，本 doc 未重新实测） |
